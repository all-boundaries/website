# Surface brief: All Boundaries site identity (docs + landing)

Mode: Read (docs and pattern pages); the landing page is a Persuade-leaning cover inside the same system.
Audience and job: engineers, tech leads, architects, directors and executives; find the pattern for a problem, see it in real code and diagrams, follow it up from one service to team structure. Agents read the raw twins.
Constraints: Starlight/Astro, Mermaid inline SVG, WCAG AA, light and dark, no invented claims.
Unresolved: companion repo URL for the take-part link; diagram zoom.

## Direction contract

THESIS: A shelf of technical guides: every family of boundaries is a flat colour with fine line art, so a catalogue spanning code to organisation scans like a library. Refuses the default docs arrangement of one blue accent and unbranded sidebar.
OWN-WORLD: Mist (#f6f9fc) or deep navy (#0a1628) ground, navy ink, indigo for action only, four flat family colours (cobalt, tangerine, rose, violet) with 1px geometric line art, 12px rounded panels, navy code panels, Figtree for everything, mono only for code and small labels.
STORY: The visitor understands that boundaries at every scale are one problem, believes the patterns are real because each ties to code, and goes to the family card for their problem or the example.
FIRST VIEWPORT: Header with wordmark, search, four mono section links; left column with a large statement, lede and an indigo pill "Meet the example"; right a staggered 2x2 of family cards, each with title, one line and line art.
FORM: Pinned by the user's references (Stripe Guides, Stripe Docs, opencode docs); no concept roll was run; seed: none (unavailable).
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
