# Surface brief: All Boundaries site identity (docs + landing)

Mode: Read (docs and pattern pages); the landing page is a Persuade-leaning cover inside the same system.
Audience and job: engineers, tech leads, architects, directors and executives; find the pattern for a problem, see it in real code and diagrams, and follow it up from one service to team structure. Agents read the raw twins.
Constraints: Starlight/Astro, Mermaid inline SVG, WCAG AA, light and dark, no invented claims.
Unresolved: logo mark refinement, per-family geometry, grid-toggle persistence.

## Direction contract

THESIS: One visible modular grid governs every page, so a catalogue spanning code to organisation reads as one calm intelligence. Refuses the default docs arrangement of blue-accent sidebar, system sans and soft cards.
OWN-WORLD: Unprinted white (and poster black) ground, black grotesque ink, one signal red marking the current selection only; flush-left Hanken Grotesk headings stepped in grid units, Source Serif 4 reading column, flat geometry (bars, arcs, squares) as the only imagery, one geometric motif per family of patterns; typographic controls, no rounded cards, no shadows.
STORY: The visitor understands that boundaries at every scale are the same problem, believes the patterns are tested because each ties to real code, and goes to the pattern for their problem or follows a journey.
FIRST VIEWPORT: Top rule with wordmark, current family and pattern ID; left rail of families and patterns with a red bar under the current page; a very large flush-left title across the column span; a 65-75ch serif reading column on modules 2-6 and a geometric motif on the right modules; the way forward (contents, next/previous) stays in the rail and the foot.
FORM: Swiss International Style poster wall (design-canon-swiss-grid-poster-wall), the user's pick, 3rd on the ordered list; seed:5a5bba0bdb496bc9.
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
